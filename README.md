# Vauvan hankinnat

Vain luettava katselunäkymä vauvan hankintalistasta. Sivu (`index.html`) lukee tiedot tiedostosta `data.json`, joka päivitetään automaattisesti ostoslistatyökalusta (`tools/snapshot.py`).

## Vanhempainvapaan laskuri

Kansiossa `vanhempainvapaa/` on vanhempainvapaan laskuri (Kelan päivärahat, kiintiöt, verot ja vuosilomat). Tiedot tallentuvat vain käyttäjän omaan selaimeen.
